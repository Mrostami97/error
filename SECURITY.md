# Security Policy

## Supported versions

The current `0.1.x` line is the supported development line while the project is in early alpha.

## Data handling

The current project processes files locally and makes no network or API calls. Future model-assisted features, if added, must be opt-in and document exactly what content leaves the local machine.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for this repository when it is available. Do not publish secrets, sensitive documents, exploit details, or personal data in a public issue.

If private vulnerability reporting is unavailable, open a minimal public issue requesting a private contact channel and omit sensitive technical details until a private channel is established.
